# Gemini連携（読解・Part6・リスニングPart3/4 の詳細解説）

長文3分野を Gemini で処理するための一式です。`tools/words/`（ChatGPT用）と同じ考え方で、
チャンクを貼って→結果を保存して→スクリプトで検証・反映、の流れです。

| フォルダ | 対象 | チャンク数 | 1チャンクあたり |
|---|---|---|---|
| `reading/` | 読解 Part7（194文書） | 25 | 8文書 |
| `part6/` | 長文穴埋め Part6（125文書） | 9 | 15文書 |
| `part34/` | リスニング Part3・4（169セット） | 22 | 8セット |

## 各フォルダの使い方（共通）
1. `<フォルダ>/PROMPT.md` の【指示文】をGeminiに貼る
2. `<フォルダ>/chunks/chunk_01.json` の中身を貼る
3. 返ってきたJSONを `<フォルダ>/results/result_01.json` として保存する
4. chunk_02 以降を繰り返す
5. `python tools/gemini/<フォルダ>/import_results.py --dry-run` で検証
   - OKなチャンクだけ反映されます。NGは理由が出るので、そのチャンクだけ再生成してください
   - 問題なければ `--dry-run` を外してもう一度実行すると実際にファイルに書き込まれます
   - 何度実行しても安全です（結果は上書きされるだけ）

## Geminiを使う理由
- 1回で読める文章量が大きいので、長文パッセージ＋設問をまとめて渡せる
- チャットが長くなってきたら、新しいチャットに切り替えて `PROMPT.md` の【指示文】から貼り直してください（Gemini側の制限に引っかかった場合も同様）

## 反映後の確認
アプリ側（`ReadingStudy` / `Part6Study` / `ListeningPart34Study`）は、データに
`passageJa` / `choicesJa` / `explanationDetail` / `scriptJa` / `vocab` があれば、
解答後に「全訳・重要語句」の折りたたみが自動で出るようになっています。
データがない問題は今まで通りの表示のままなので、途中まで反映した状態でも壊れません。
