# TOEIC Drill

自分専用のTOEIC学習アプリ（単語・文法）。React + Vite + TypeScript + Tailwind CSS製、バックエンド不要。学習データはブラウザのlocalStorageに保存されます。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:5173` で確認できます。

## ビルド

```bash
npm run build
npm run preview   # ビルド結果をローカルで確認
```

## スマホからもアクセスする（デプロイ）

無料でVercelにデプロイすると、PCでもスマホでも同じURLでアクセスできます。

1. このプロジェクトをGitHubリポジトリにpush
2. [Vercel](https://vercel.com) にログインし、「New Project」からリポジトリを選択
3. フレームワークは自動検出（Vite）されるのでそのままデプロイ
4. 発行されたURLをスマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます

## 機能

- **単語学習**：フラッシュカード形式。「わかる/わからない」で間隔反復（簡易版SM-2）により復習タイミングを自動調整
- **文法問題**：Part 5形式の一問一答、即時採点＋解説
- **進捗画面**：正答率、直近14日間の学習量グラフ、難易度別の弱点分析
- **予想スコア**：直近の正答率と問題難易度から、文法・語彙パートの目安スコアをホーム画面に表示（参考値）
- **復習機能**：単語・文法それぞれについて「間違えた問題だけ」「ブックマークした項目だけ」「今日の出題予定に関係なく全部」の3パターンで、いつでも復習できます。学習中の各カード右上の★ボタンでブックマークのオン/オフができます

## 問題データを増やす

`src/data/words.json` と `src/data/grammar.json` に同じ形式でオブジェクトを追記するだけで、問題を追加できます（現在：単語300語、文法問題100問）。

```json
{ "id": "w051", "word": "...", "meaning": "...", "example": "...", "level": 600 }
```

```json
{ "id": "g031", "question": "...", "choices": ["...", "...", "...", "..."], "answer": 0, "explanation": "...", "level": 600 }
```

`id` は既存のものと重複しないようにしてください。TOEIC公式問題はETSの著作権で保護されているため使用できません。Claudeにお願いして新しい問題セットを生成してもらうのが手軽です。

## データのリセット

進捗をリセットしたい場合、ブラウザの開発者ツールで以下を実行してください。

```js
localStorage.removeItem("toeic-drill-data-v1");
```
