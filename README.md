# TOEIC Drill

自分専用のTOEIC学習アプリ（単語・文法）。React + Vite + TypeScript + Tailwind CSS製、バックエンド不要。学習データはブラウザのlocalStorageに保存されます。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:5173` で確認できます。

## ビルド

```bash
npm run build
npm run preview   # ビルド結果をローカルで確認
```

## スマホからもアクセスする（デプロイ）

無料でVercelにデプロイすると、PCでもスマホでも同じURLでアクセスできます。

1. このプロジェクトをGitHubリポジトリにpush
2. [Vercel](https://vercel.com) にログインし、「New Project」からリポジトリを選択
3. フレームワークは自動検出（Vite）されるのでそのままデプロイ
4. 発行されたURLをスマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます

## 機能

- **単語学習**：フラッシュカード形式。「わかる/わからない」で間隔反復（簡易版SM-2）により復習タイミングを自動調整
- **文法問題**：Part 5形式の一問一答、即時採点＋解説
- **進捗画面**：正答率、直近14日間の学習量グラフ、難易度別の弱点分析
- **予想スコア**：直近の正答率と問題難易度から、文法・語彙パートの目安スコアをホーム画面に表示（参考値）
- **復習機能**：単語・文法それぞれについて「間違えた問題だけ」「ブックマークした項目だけ」「今日の出題予定に関係なく全部」の3パターンで、いつでも復習できます。学習中の各カード右上の★ボタンでブックマークのオン/オフができます
- **初回模試**：単語・文法あわせて30問（レベル400〜850を満遍なくカバー）の模試を受けると、初回から目安スコアが表示されます
- **おすすめ問題**：模試や日々の学習の正答率・レベルから「今ちょうどいい難易度」を推定し、習熟済みの項目を避けつつ的を絞って出題します（ホーム画面・復習画面からアクセス可能）
- **リーディング問題（フェーズ2）**：Part 7形式の読解問題（110パッセージ・設問410問）。社内メモ、求人広告、顧客案内、契約更新通知、製品リコールなど幅広いビジネス文書をカバー。シングルパッセージ70本に加え、2つの文書を読んで答えるダブルパッセージ25セット、3つの文書を読んで答えるトリプルパッセージ15セットを収録し、本番のPart 7構成に近い比率まで拡充している。間隔反復にも対応しています。単語・文法と同様、復習画面から「間違えたパッセージ」「ブックマーク」「すべて」を復習できます（おすすめ問題モードは単語・文法のみ対応）
- **長文穴埋め問題（Part 6形式）**：本文中の4つの空欄それぞれに文法・語彙問題が仕込まれた形式（20パッセージ・設問80問）。単語・文法・リーディングと同じ復習の仕組みに完全対応
- **リスニング問題（Part 2形式、フェーズ3着手）**：応答問題30問のスターターセット。音声はブラウザ標準のWeb Speech API（`speechSynthesis`）で生成しており、外部API・バックエンドを一切必要としません。設問と選択肢A/B/Cを順番に読み上げ、再生速度（0.75x/1.0x/1.25x）を切り替え可能。テキストは解答するまで表示されず、本番同様「聞いて選ぶ」練習になります。音声非対応ブラウザでは自動的にテキスト表示にフォールバックします。単語・文法・リーディング・Part 6と同じ間隔反復・復習（間違えた問題／ブックマーク／すべて）・進捗集計に対応

## 問題データを増やす

`src/data/words.json` と `src/data/grammar.json` に同じ形式でオブジェクトを追記するだけで、問題を追加できます（現在：単語2000語、文法問題1000問）。

```json
{ "id": "w051", "word": "...", "meaning": "...", "example": "...", "level": 600 }
```

```json
{ "id": "g031", "question": "...", "choices": ["...", "...", "...", "..."], "answer": 0, "explanation": "...", "level": 600 }
```

`id` は既存のものと重複しないようにしてください。TOEIC公式問題はETSの著作権で保護されているため使用できません。Claudeにお願いして新しい問題セットを生成してもらうのが手軽です。

## データのリセット

進捗をリセットしたい場合、ブラウザの開発者ツールで以下を実行してください。

```js
localStorage.removeItem("toeic-drill-data-v1");
```
