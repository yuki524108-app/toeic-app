# 問題データの品質チェック

## 使い方
```
python3 tools/quality/check.py            # 概要を表示。全件は tools/quality/report.json
python3 tools/quality/check.py --strict   # ERROR があれば終了コード1
```
- 検査するもの：選択肢の重複・空欄、正解と解説の食い違い、文法の完成文（問題文＋正解と一致するか、「in next fall」型の非文がないか）、
  Part 6の空欄数、単語の例文、完全な重複（文法・Part 2）、似た問題文、正解が最長の選択肢に偏っていないか。
- 確実に誤りと言えるものは自動テスト（`tests/data/quality.test.ts`）でも守っている。
- この検査では見つからないもの：**正解が1つに決まるか**（他の選択肢も文法的に成り立つ）、解説の内容の正しさ。
  これは実際に解いて確かめるしかない。結果は `manual_review.json`（未修正の疑わしい問題と、解き終えた範囲）。
