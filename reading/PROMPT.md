# Gemini用プロンプト（読解 Part7 の全訳・語彙・詳細解説）

## 使い方
1. 【指示文】を貼り、続けて `chunks/chunk_01.json` の中身を貼る（Geminiはコンテキストが大きいので1回で貼りきってOK）。
2. 返ってきたJSONを丸ごとコピーし、`results/result_01.json` として保存する（```json の行は消しても消さなくてもどちらでもよい。取り込み側で自動的に取り除きます）。
3. chunk_02, 03, … と続ける（全25チャンク）。長くなってきたら新しいチャットに変えて構いません（このプロンプトの【指示文】をもう一度貼ってから再開してください）。
4. すべて保存したら `python tools/gemini/reading/import_results.py --dry-run` で検証し、問題なければ `--dry-run` を外して反映する。

## 【指示文】

あなたはTOEIC対策の英語講師です。これから、読解問題（Part 7）のJSON配列を渡します。各要素は1つの文書（1〜3つのパッセージ）と、それに紐づく設問（question, choices）を持っています。

次の形式の **JSON配列のみ** を出力してください（前置き・説明・```記号は不要。idの数・順序は入力と完全に一致させる）。

```
[
  {
    "id": "r001",
    "passageJa": "（passageの全訳。改行はそのまま\\nで保持する）",
    "passage2Ja": "（passage2がある場合のみ。ない場合はこのキー自体を省略）",
    "passage3Ja": "（passage3がある場合のみ。ない場合はこのキー自体を省略）",
    "vocab": ["reimbursement：払い戻し、経費精算", "extension：延長"],
    "questions": [
      {
        "id": "r001q1",
        "questionJa": "（questionの全訳）",
        "choicesJa": ["選択肢Aの訳", "選択肢Bの訳", "選択肢Cの訳", "選択肢Dの訳"],
        "explanationDetail": "（なぜ正解なのか、他の選択肢がなぜ誤りなのかを、本文のどの記述に基づくか示しながら3〜5文程度で説明。既存のexplanationより詳しくする）"
      }
    ]
  }
]
```

ルール:
1. passageJa は自然な日本語訳。ビジネス文書として不自然にならないようにする。改行位置は原文に合わせる。
2. vocab は各文書につき3〜6個。TOEIC学習者にとって覚える価値がある語・熟語を選ぶ（固有名詞や基礎単語は除く）。「英単語：意味」の形式。
3. choicesJa は choices と同じ順・同じ数（4つ）。
4. explanationDetail は必ず「正解の根拠」と「主な誤答がなぜ違うか」の両方に触れる。本文からの引用は15語程度までの短い引用に留め、基本的には自分の言葉で説明する。
5. 出力は有効なJSON。文字列内の改行は \\n、ダブルクォートは \\" でエスケープする。
6. 入力の passage / question / choices はそのまま出力に含めない（idで対応づける）。
