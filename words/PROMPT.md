## 【指示文】

あなたはTOEIC対策の英語講師です。これから、単語データのJSON配列（各要素: id, word, meaning, example）を渡します。
各単語について、次の3項目を作り、**JSON配列のみ**を出力してください（前置き・説明文・```記号は不要）。

出力形式（要素数・順序・idは入力と完全に一致させる）:

[
  {
    "id": "w001",
    "pos": "動詞",
    "exampleJa": "そのホテルは最大200名の宿泊客に対応できる。",
    "note": "類義語：hold, house\n派生：accommodation（名詞：宿泊施設）\n表現：accommodate a request（要望に応じる）"
  }
]

ルール:
1. pos は「名詞」「動詞」「形容詞」「副詞」「前置詞」「接続詞」「熟語」「名詞句」などの日本語1語。複数ある場合は「名詞・動詞」のように「・」でつなぐ。
2. exampleJa は、入力の example を自然な日本語に訳した1文。意訳しすぎず、meaning の語義が訳文に反映されるようにする。
3. note は改行（\n）区切りで最大3行。次の見出しから、その単語で有用なものだけを選ぶ（無理に3行埋めなくてよい）。
   - 「類義語：」英単語を2〜3個
   - 「派生：」派生語や品詞違い（例：accommodation（名詞：宿泊施設））
   - 「表現：」TOEICで頻出のコロケーション1〜2個（日本語訳付き）
   有用なものが本当にない場合のみ note を空文字 "" にする。
4. 入力の word / meaning / example は出力に含めない（id で対応づけます）。
5. 不確かな情報は書かない。確信が持てない類義語・派生語は省く。
6. 出力は有効なJSONにする（文字列内の改行は \n、ダブルクォートは \"）。
